# Daily Operations Checklist — Marcus Jay Herring LLC

**What to do every day/week to keep operations smooth and never miss a beat.**

---

## Daily (Morning Routine — 10 minutes)

**Start your workday with this checklist:**

### Check Inbox & Messages
- [ ] Read all emails received
- [ ] Respond to time-sensitive messages
- [ ] Flag urgent items for action today

### Check Job Status
- [ ] Open `JOB_STATUS_TRACKER.md`
- [ ] Any jobs due today? (flights, deliverables)
- [ ] Any overdue items? (quotes, proposals)

### Check Weather
- [ ] Open weather app
- [ ] Flyable today? (wind < 20 mph?)
- [ ] Schedule flight if conditions permit

### Priority List
- [ ] Write down 3 things to complete today
- [ ] Focus on most urgent first

---

## Daily (End of Day Routine — 5 minutes)

**Before you stop working:**

### Log Progress
- [ ] Did a flight happen today? → Log in `FLIGHT_LOG_TEMPLATE.md`
- [ ] Process any footage? → Back up files
- [ ] Send any deliverables? → Log in tracker
- [ ] Receive payment? → Log in `PAYMENT_TRACKING.md`

### Update Tracker
- [ ] Move any jobs to next stage in `JOB_STATUS_TRACKER.md`
- [ ] Note any issues for tomorrow

### Backup
- [ ] Any new files created? → Back up to Dropbox + local drive
- [ ] SD cards from flight? → Copied to computer + backed up

---

## Weekly (Friday — 30 minutes)

### Review & Update
- [ ] Open `JOB_STATUS_TRACKER.md`

### Financial Check
- [ ] Open `PAYMENT_TRACKING.md`

- [ ] Any deposits received? (log in bookkeeping)

### Weekly Metrics
- [ ] Jobs completed this week: ________
- [ ] Revenue this week: $________
- [ ] Positive feedback this week: ________
- [ ] On track for Stage 0 gate? ☐ Yes ☐ No

### Feedback & Learnings
- [ ] Any client feedback arrived? (log it)
- [ ] Any issues this week? (document lesson learned)
- [ ] What to improve next week?

### Next Week Planning
- [ ] How many flights scheduled? ________
- [ ] Any follow-ups needed? (quotes, proposals)
- [ ] Any partnerships to outreach? (check `SALES_PARTNERSHIP_FRAMEWORK.md`)

## Critical Alerts (Monitor Weekly)

**These require IMMEDIATE action:**

| Alert | What to Do |
|-------|-----------|
| No jobs scheduled in next 2 weeks | Start outreach to prospects immediately |
| Overdue invoice >30 days | Call client today, offer payment plan |
| Equipment malfunction | Document, assess impact, notify client if affecting job |
| Insurance about to lapse | Call carrier to renew ASAP (no flying without it) |
| Client complaint on quality | Offer revision or refund immediately |
| Weather blocks 2+ flights | Reschedule early, communicate status to clients |

## Time Allocation (Weekly)

**How to spend your 40 hours/week:**

- **Flying jobs:** 50% (20 hours) — Stage 0: 3-5 jobs/month
- **Processing/delivery:** 25% (10 hours) — Editing, reporting
- **Operations/admin:** 15% (6 hours) — Quotes, invoices, tracking
- **Sales/partnerships:** 10% (4 hours) — Outreach, follow-ups

**As you grow:** Percentages will shift. But always protect flight + delivery time.
