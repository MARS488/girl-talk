# Insurance Call Script — Ready to Use

**Not a guide about insurance. The actual script for the actual call. Real carrier names, the exact questions already confirmed necessary, and blank lines to fill in as you go. This is the one artifact between "read about it" and "done."**

## Before you dial

You need answers for **two** policies in as few calls as possible:
1. **Drone liability** (~$1M) — SkyWatch, Thimble, or Avion
2. **Training liability** ($1M/$2M) — K&K Insurance's ISSA-accepted Fitness Instructor/Personal Trainer program

Have ready: EIN (41-2527098), LLC name (Marcus Jay Herring LLC), Part 107 cert #5051412, drone tail number FA39HTPANE.

## After both calls — the decision

You don't need the cheapest option. You need the one that:
- Says yes to subcontractor coverage (or you know now to never sub out a job until this changes)
- Confirms the TENS/e-stim question in writing
- Can actually bind this week

**Once you pick:**
- [ ] Bind both policies
- [ ] Request the Certificate of Insurance (COI) for each
- [ ] Save COIs to `LLC Business/Insurance/` in Dropbox
- [ ] Update the Notion Command Center gate item — this is the one that unblocks everything else

---

## If you get put on hold or told to "check back"

Ask directly: **"Can you bind this today, or do I need to wait on underwriting?"** On-demand drone policies (SkyWatch/Thimble) are usually instant. If a carrier can't give you a same-day answer, that's useful information — try the next one on the list rather than waiting.
